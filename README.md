# E-Commerce-Sales-Analysis-SQL

## Project Overview

This project analyzes e-commerce sales data using SQL and visualizes business insights with Power BI.

## Tools Used

- MySQL
- SQL
- Power BI
- GitHub

## Database Tables

- Customers
- Products
- Orders
- Order Items

## Key SQL Concepts

- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions

## Business Insights

- Total Revenue
- Top Selling Products
- Top Customers
- Revenue by Category
- Sales Trend
- Orders by State
